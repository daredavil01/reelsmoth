# videos/

One folder per video: `videos/<slug>/` holds `brief.md`, `spec.md`, `timeline.json`, `README.md` and (gitignored) `master.*`, `draft.*`, `stills/`, `exports/`, `contact-sheet.png`.

Masters and exports are not committed. Upload them to R2 or S3 and record URLs in `videos/manifest.json` (Phase 7).
